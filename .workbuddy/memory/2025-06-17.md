# 2025-06-17

## ArtisanSteel 不锈钢雕塑 B2B 网站搭建

### 技术栈
- Next.js 16.2.9 + React 19.2.4 + TypeScript
- Tailwind CSS v4 + shadcn/ui
- GSAP + Motion (framer-motion successor) + Lenis (smooth scroll)
- Three.js + React Three Fiber + ogl (WebGL)
- next-intl (i18n: en/ar/es/fr)

### 已移植的 React Bits 组件
- **Animations**: MetallicPaint (WebGL金属漆), LiquidChrome (液态铬背景), FadeContent, SplashCursor
- **Components**: TiltedCard (3D倾斜), SpotlightCard (聚光灯), CircularGallery (3D圆形画廊), Counter
- **TextAnimations**: BlurText, ScrollReveal, GradientText, ShinyText

### 页面结构
- /[locale] — 首页 (Hero + Sculpture Grid + Why Us + Case Studies + Process + CTA)
- /[locale]/sculptures — 雕塑分类展示页
- /[locale]/case-studies — 案例列表 + /case-studies/[id] 详情页
- /[locale]/custom-design — 定制设计服务
- /[locale]/materials — 材料与表面处理 (304/316L/镜面/拉丝)
- /[locale]/installation — 全球安装服务
- /[locale]/about — 关于我们
- /[locale]/contact — 联系/RFQ 表单 + WhatsApp 悬浮按钮

### 设计特色
- 纯黑背景 + 不锈钢/液态金属视觉主题
- LiquidChrome WebGL 背景 (Hero section)
- SpotlightCard + TiltedCard 交互卡片
